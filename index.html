Architecture & Security

Engine Highlights

Engineered for maximum portability, high speed, and complete privacy.

100% Client-Side Privacy

No telemetry, no remote uploads, and zero API proxies. Image buffers are decoded and processed purely in browser memory using HTML5 ArrayBuffer and Canvas APIs.

Modular Core Pipeline

Every codec implements an identical functional signature mapping bytes to an ImageBuffer (linear 32-bit RGBA) and back, decoupling decoders from encoders cleanly.

Hardware Acceleration

Native web formats leverage browser-level multi-threaded pipelines via createImageBitmap and OffscreenCanvas, transcoding heavy assets in milliseconds.

Retro & Next-Gen Codecs

Includes pure JavaScript byte-level decoders for fast next-generation formats like QOI (Quite OK Image), retro gaming standards like TGA, and Unix PPM/PNM.

WebAssembly Extension Layer

Modular adapter bridge pre-configured to easily hook into compiled C/C++ or Rust libraries (such as LibRaw, LibJXL, and ImageMagick-WASM) for multi-layer and RAW images.

GitHub Pages Native

Zero build tools or compilation steps needed. Deploy straight to GitHub Pages or static hosts with native ES Module imports and valid MIME handling.
